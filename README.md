# 🎂 小羊同学 · 生日纪念网页

送给 **小羊同学** 的生日礼物 —— 一个喜欢马嘉祺的女孩，和所有喜欢她的人。

> 页面里的马嘉祺素材，是他；收礼人是小羊同学。  
> 最后的祝福以马嘉祺的口吻写给她，落款笔名 **soulmate**。

## 使用方法

### 方式一：直接双击（最简单）

双击 `index.html` 即可用浏览器打开。**整个文件夹必须一起保留**，  
`assets/` 和 `data/` 目录不能删、不能单独发 index.html。

### 方式二：本地起服务（推荐，兼容性最好）

在文件夹内打开命令行执行：

```bash
python -m http.server 8000
```

然后浏览器访问 <http://127.0.0.1:8000>

### 方式三：部署到公网（拿到可分享的链接）

把整个文件夹上传到任意静态托管服务（GitHub Pages / Vercel / Netlify /  
对象存储 COS+CDN 等），然后把生成的网址发给对方即可。

**详细步骤见 `DEPLOY.md`。**

> 第 06 栏「接下来，等你」的动态数据来自 `data/live.js`，
> 是构建时（2026-10-25）从公开网络抓取的真实内容快照。
> 之所以做成快照而非运行时实时请求：第三方热榜接口在浏览器端
> 受 CORS 与限流影响，直连不稳定；快照 + 官方入口直达反而更可靠。

## 🎵 自定义背景音乐（把他的歌设成背景）

网页默认使用 **Mixkit 免费商用音乐**（6 首，无需署名）。

如果想换成 **马嘉祺本人的歌**，需要你自己放入音频文件：

### 步骤

1. 把你**合法获取**的音频文件（mp3 / m4a / wav / flac / ogg / aac）放进：
   ```
   assets/music_sel/
   ```
   文件名即曲名，建议这样命名：
   ```
   assets/music_sel/唯我论者的独白.mp3
   assets/music_sel/如是春.mp3
   assets/music_sel/冰箱没有鸡蛋.mp3
   ```
2. 运行注册脚本：
   ```bash
   python addmusic.py
   ```
   脚本会自动扫描目录，更新 `data/music_custom.json` 和 `assets/data.js`，  
   并打印添加了哪些曲目。
3. 刷新网页 —— 这些曲目会自动加入背景音乐轮播，播放器上也会显示曲名。

### 其他用法

```bash
python addmusic.py "唯我论者的独白.mp3"   # 只注册指定文件
python addmusic.py --clear                # 清空自定义清单（默认曲库保留）
```

### ⚠️ 关于版权

马嘉祺演唱的歌曲是**受版权保护的商业录音**，打包进网页再分发给第三方  
可能涉及侵权。所以这个网页**没有**内置他的歌曲音频，而是提供两条路：

- **歌单墙**（第 05 栏）：列出他的代表作，点击直达 QQ 音乐等官方平台收听
- **自定义音乐**：你自己放入合法获得的音频，网页自动识别并播放

> 个人自用、私下分享给朋友属于个人使用范畴，风险较低；  
> 但若要公开发布或商业使用，请确认你所用音频的授权。
